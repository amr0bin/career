# 💾 Data Management Plan (DMP)

> **How research data will be collected, stored, protected, shared and kept — written before collection.**
> Funders and ethics boards now expect a DMP. For your pilot it also does a specific job: the consent and DMP wording decide whether pilot data can inform the MA thesis.

---

## 1. The structure

| Part | What it does | Notes |
|---|---|---|
| Data description | What data, in what formats, how much | Survey data, audio, transcripts, documents |
| Documentation and metadata | Data dictionary, codebook, README |  |
| Storage and backup | Where, encrypted, how often backed up | Institutional storage, not personal cloud |
| Privacy and security | De-identification steps, access controls, retention | TCPS 2 chapter 5 |
| Sharing and reuse | What will be shared, where, under what licence | Future-use consent if data will inform later research |
| Preservation | Repository, retention period, destruction | Borealis (Canadian Dataverse) or OSF |
| Responsibilities | Who does what |  |

---

## 2. How to do it well

1. Use the free DMP Assistant (Digital Research Alliance of Canada) or the Leeds template.
2. Write the consent form and the DMP together, so they promise the same things.
3. Include future use explicitly: anonymised pilot data and instruments may inform later research, including a master's thesis.
4. Separate identifiers from data on day one.
