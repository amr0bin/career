## The one rule that makes it efficient: write once, reuse many times

| Write this once | It becomes |
|---|---|
| Annotated bibliography (in Zotero) | Leeds literature essays → MA literature chapter → a standalone review paper |
| Ethics application | Methods chapter → the methods section of the empirical paper |
| Leeds module essays (written *to become* chapters) | The MA thesis proposal = the CGRS M proposal |
| The paper's propositions or results table | Abstract → poster or talk → policy brief → plain-language piece |
| Weekly development log | Reflective essays → clinical portfolio → statements |
| The invented-case casebook | Adjudication evidence for the advisor role → the thesis's process-feature list |

## House rules that apply to every guide

No AI on any application itself (statements, reference requests, video answers). Nothing client-derived, ever. Never from your own workplace. Only invented cases to show adjudication skill. Pre-licensure words in public. Plans private, products public. Full text: [`../philosophy/house-rules.md`](../philosophy/house-rules.md).
