# 🔓 Preregistration, Protocols & Open Science Deposits

> **Time-stamped plans, preprints and data deposits that make independent research credible.**
> Without an institution, preregistration is the deadline and the credibility an institution would otherwise supply. It also protects you: if a result inverts the prediction, saying so is believable.

---

## 1. The structure

| Part | What it does | Notes |
|---|---|---|
| Study information | Title, question, hypotheses or aims | Qualitative aims are welcome |
| Design plan | Design, sampling frame, stopping rule |  |
| Data collection | Sources, procedures, what exists already | Declare any data already seen |
| Variables / codes | Measures, or the coding frame with definitions | Attach the coding manual |
| Analysis plan | How each aim will be answered; agreement statistics | What would count as disconfirmation |
| Deviations log | Added after: every change, with date and reason | Honest deviations are normal |

---

## 2. How to do it well

1. Register on OSF Registries; use the OSF Preregistration template, or the qualitative template for document or interview studies.
2. Register scoping reviews on OSF; PROSPERO does not accept scoping reviews.
3. Post preprints to EdArXiv, SSRN or PsyArXiv on submission day; check the journal's preprint policy first.
4. Deposit the dataset and coding manual on OSF with a licence (CC BY) and a DOI when the paper is accepted.
5. Keep a dated deviations log from day one.

- Peters, M. D. J., et al. (2020). Updated methodological guidance for the conduct of scoping reviews. *JBI Evidence Synthesis, 18*(10), 2119–2126.

### ⚡ Do it well and fast

- Write the preregistration and the methods section as one document.
- Use OSF's embargo option if you need privacy before submission.
