# 🔎 Accessibility Audit & Review Report

> **A structured finding of where a course, document, site, process or space excludes people, and what to change first.**
> Advisors, learning designers and CPACC holders are asked for this constantly. A good audit report is prioritised, standards-referenced and written so the owner can act on it the next morning.

---

## 1. The structure

| Part | What it does | Notes |
|---|---|---|
| Scope and method | What was reviewed, against which standard, with which tools and people | Name the standard version (e.g. WCAG 2.2 AA) |
| Summary for decision-makers | Three to five headline findings and the order to fix them | One page; the only page some readers will see |
| Findings | Each barrier: where, who it affects, the standard it fails, severity, evidence | Screenshots or steps to reproduce |
| Recommendations | A fix for each finding, with effort and owner | Quick wins first, then structural changes |
| Process findings | Barriers in the *process* (request forms, timelines, documentation) not just the artefact | Where your thesis lens adds value |
| Lived-experience review | What disabled users found that automated tools missed | Paid, credited reviewers |
| Appendices | Full issue log, tools, test matrix |  |

---

## 2. How to do it well

1. Fix the scope before testing; an audit that grows mid-stream never finishes.
2. Combine three methods: automated checks, manual expert review, and testing with disabled users.
3. Rate severity by impact on completing the task, not by count of failures.
4. Separate *artefact* barriers (a PDF without tags) from *process* barriers (a form that must be re-submitted every term).
5. Write each recommendation as a verb and an owner.
6. Close with a re-test date.

## 🧭 Credible examples, fast path and where this sits now

### 📚 Credible examples

- W3C. (2023). *Web Content Accessibility Guidelines (WCAG) 2.2*. W3C Recommendation.
- W3C WAI. *WCAG-EM: Website Accessibility Conformance Evaluation Methodology*.
- ITI. *VPAT® / Accessibility Conformance Report* template — the procurement-standard reporting format.
- *Accessible British Columbia Act* (2021) — the provincial frame for organisational accessibility plans and committees.
- CAST. (2024). *Universal Design for Learning Guidelines* (version 3.0) for course-level reviews.

### ⚡ Do it well and fast

- Reuse one issue-log spreadsheet for every audit; the report is generated from it.
- Audit your own public resources first (Accessible Learning Labs) — publishable practice on your own work.
