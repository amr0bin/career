# career

The reference home for one arc: from disability studies and accessibility advising, through counselling and art therapy, to a counselling psychology doctorate, teaching and a practice of my own.

**This repo holds why. The [Career & Education OS](https://app.notion.com/p/40bd55c9671b8189b117fce261ed1479) in Notion holds what's next.**
If it is still true when the task is done, it lives here. If it has a status, a date, a count or a checkbox, it lives in Notion. Every file below names the Notion database that carries it out; every Notion row links back to the file that explains it.

## Where this sits in my life

Three systems run side by side, on purpose kept separate: this repo with the Notion OS (career and education); Studio Day (`amr0bin/studio-day`, the art practice); and my private personal systems, which never appear here. Planning across them happens in each one's weekly rhythm, not by merging them.

## Which file governs

1. A dated record in `decisions/` governs anything older that disagrees with it.
2. `facts/stability-and-figures.md` governs every figure; `facts/verification-register.md` lists what is not yet confirmed.
3. `arc/` governs the plan; `options/` holds what was considered and why it wasn't chosen.
4. `archive/` never governs.

## House rules for this repo

- Plans stay private; products go public. This repo holds reasoning, not records: no transcript, grades, hours, supervision logs, health history, client material or private contacts. Those live in Notion's Private section.
- Facts carry a status (verified, expected, target) and a source.
- "Over the past decade."
- When something is decided, write the reasoning to `decisions/`, then update the file it changes.
