LXD Reference Repo

Learning Design Repository

A personal reference hub for learning experience design practice — covering workflow, models, tools, templates, and collaboration skills.

📁 16 reference files + core templates
🔄 20-stage workflow mapped end-to-end
⚡ Agile-first · iterative design
♿ Accessibility · UDL 3.0 · WCAG 2.2
💡

How to use this repository: Start with 00_role_overview.md for orientation, then use 01_workflow_reference.md to navigate the full project lifecycle. Each file links to related files — follow the See also prompts at the bottom of each page. The 12_templates_index.md lists every reusable template and which workflow stage it supports.
