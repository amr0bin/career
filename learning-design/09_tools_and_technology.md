# 09 · Tools and Technology

## Overview

The learning design technology ecosystem is broad. This file organises tools by function, describes what each category is for, and notes key considerations for tool selection. Specific tools listed are widely used at the time of writing — always check your institution's current licensing and support.

> The best tool is the one your SME can maintain after you leave the project.

---

## Learning Management Systems (LMS)

The LMS is the primary course delivery environment. LXDs spend significant time designing within and configuring the LMS.

| Platform | Common In | Notes |
|---|---|---|
| **Canvas** | Higher education (North America) | Strong UDL and accessibility features; widely adopted |
| **Moodle** | Higher ed globally; open-source | Highly customisable; requires more technical maintenance |
| **Brightspace (D2L)** | Higher ed; K–12 | Strong analytics tools; good accessibility |
| **Blackboard / Anthology** | Higher ed | Older platform; being phased out at many institutions |
| **Absorb LMS** | Corporate L&D | Strong reporting; not common in higher ed |
| **TalentLMS** | Corporate / SME L&D | Lightweight; quick to set up |

**LMS Design Best Practices:**
- Consistent module structure across the whole course
- Clear, self-contained instructions on every page
- Minimal clicks to reach content (max 2–3 levels of nesting)
- Test as a student before launch (use student view)
- Ensure all linked tools and media are accessible within the LMS

## Authoring Tools (eLearning Content)

Authoring tools are used to create interactive eLearning content outside the LMS, which is then embedded or linked.

| Tool | Best For | Notes |
|---|---|---|
| **Articulate Storyline 360** | Complex interactive content, branching scenarios, simulations | High capability; steep learning curve; subscription required |
| **Articulate Rise 360** | Responsive, modern-looking eLearning quickly | Easier than Storyline; less interactive flexibility; great for mobile |
| **H5P** | Interactive content within the LMS (quizzes, interactive video, accordion, etc.) | Free and open-source; integrates with Canvas, Moodle, Brightspace |
| **Adobe Captivate** | Software simulations, responsive design | Powerful but complex; good for IT training |
| **iSpring Suite** | PowerPoint-based eLearning conversion | Quick turnaround from existing slides |
| **Lectora** | Complex eLearning; strong accessibility features | Often preferred in regulated industries for WCAG compliance |

**Choosing an authoring tool:**
- What interactivity is actually needed? (Don't over-engineer)
- Can the institution support and license the tool long-term?
- Can the SME update content after handoff? (If not, choose something simpler)
- Does the output meet accessibility standards?

## AI Tools in Learning Design

AI tools are increasingly part of the LXD toolkit. Use critically and ethically.

| Tool | Potential Uses | Cautions |
|---|---|---|
| **Claude / ChatGPT / Gemini** | Drafting content, generating examples, brainstorming activities, writing rubric drafts | Always review and edit; do not publish without human review |
| **Perplexity** | Research synthesis | Verify sources independently |
| **Notebook LM (Google)** | Summarising uploaded documents; generating study guides | Good for synthesising reading lists |
| **Synthesia / HeyGen** | AI-generated video with avatars | Useful for rapid content prototyping; disclose use to learners |
| **ElevenLabs** | AI voice-over generation | Can reduce production costs for audio; disclose use |
| **Midjourney / DALL-E** | Image generation for course graphics | Check copyright; be aware of bias in generated imagery |

**Ethical considerations for AI use in LXD practice:**
- Disclose AI-generated content to learners where relevant
- Do not use AI to replace SME knowledge — use it to scaffold and accelerate
- Review all AI output for accuracy, bias, and appropriateness
- Respect institutional policies on AI use in course development

## Tool Selection Framework

When recommending or selecting tools for a project, ask:

1. **Pedagogical fit:** Does this tool support the learning goal?
2. **Learner access:** Can all learners access this tool (device, internet, cost, ability)?
3. **Accessibility:** Does this tool meet WCAG standards or have accessible alternatives?
4. **Sustainability:** Can the SME use and maintain this tool after handoff?
5. **Institutional support:** Is this tool licensed, supported, and backed up?
6. **Privacy and data:** Does this tool comply with the law that applies? In BC: **FIPPA** for public bodies such as UBC and SFU (new tools usually need a privacy impact assessment), **PIPA** for private-sector clients, **PIPEDA** for federally regulated or cross-border commercial work; FERPA and GDPR for US or EU clients.
7. **Integration:** Does this tool work with the LMS and other existing tools?
