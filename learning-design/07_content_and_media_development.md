# 07 · Content and Media Development

## The LXD's Role in Content Development

Content development is where the design comes to life. As an LXD, you are not typically the subject matter expert — you are the **architect of the learning experience** and the **collaborator who helps the SME communicate their knowledge effectively**.

Your contributions in this stage:
- Structure and sequence content for learning (not just information transfer)
- Advise on the most effective media and format for each piece of content
- Write instructional text (instructions, module introductions, activity prompts)
- Coordinate media production (video, audio, graphics, interactive elements)
- Build and configure the LMS course shell
- Manage iterative review and revision cycles

## Storyboarding

A storyboard is the blueprint for your course — it captures structure, content, media, and interactions before full production begins. Getting feedback on a storyboard is far less costly than rebuilding finished content.

### What a Storyboard Captures

| Element | Description |
|---|---|
| Module/unit structure | How the course is divided; names and sequence of sections |
| Screen-by-screen flow | For eLearning: what appears on each screen in sequence |
| Content summary | What information is presented in each section |
| Media notes | What type of media is used (video, audio, image, text) and any production notes |
| Activity descriptions | What learners will do; instructions; estimated time |
| Navigation notes | Linear or branching; any conditional logic |
| Assessment placement | Where formative checks and summative tasks appear |

### Storyboard Formats

- **Simple Word/Google Doc table** — most common for text-based courses; quick to produce; easy for SME review
- **PowerPoint/Google Slides** — useful for eLearning storyboards; one slide per screen
- **Figma or wireframing tools** — useful for complex interactive designs or when visual layout matters
- **Specialised ID tools** — Articulate Review, Lectora, etc. have built-in storyboarding

### Storyboard Review Tips
- Share early and rough — a polished storyboard invites polish critique, not pedagogical critique
- Ask SMEs to focus on **accuracy and gaps**, not formatting
- Use tracked changes or comments for asynchronous review
- Time-box review periods (e.g., "Please review by Friday; I'll incorporate feedback Monday")

## Content Chunking

Chunking is the practice of breaking content into manageable pieces that support working memory and comprehension.

**Principles:**
- One concept or skill per chunk
- Aim for 5–7 minutes of content per chunk (for video or audio)
- Use headings, white space, and visual breaks to signal chunk boundaries
- Sequence chunks from simple to complex, concrete to abstract, familiar to new

**Chunking structure for a module:**
1. **Hook / relevance** — Why does this matter? What's the problem or question?
2. **Core content** — The key concept, explained clearly
3. **Example or demonstration** — Concrete illustration of the concept
4. **Practice or reflection** — Learner does something with the information
5. **Summary / bridge** — What was covered; connection to what comes next

## Writing for Learning

Instructional writing is different from academic writing or content writing. It is designed to be **processed, not just read**.

### Principles of Clear Instructional Writing

- **Write to the learner directly.** Use "you" — it's more engaging than passive constructions.
- **Use plain language.** Aim for clarity over impressiveness. If learners have to decode your prose, they can't also be processing the content.
- **Be specific about what learners should do.** Instructions that say "explore the following" are less effective than "read the following article, then answer the reflection questions below."
- **Front-load the important information.** The most important point comes first (inverted pyramid).
- **Use consistent formatting.** Headings, bold key terms, bullet lists for parallel items.
- **Chunk and label.** Give each section a clear descriptive heading.

### Writing Module Introductions
A good module intro should:
- State the module's learning outcomes in learner-friendly language
- Explain *why* this module matters (relevance, connection to the bigger picture)
- Preview what's coming (topics, activities, assessment)
- Estimate time required

## Media Selection

Choosing the right media means matching the format to the learning goal — not just defaulting to video because it feels modern, or text because it's easy.

### Media Selection Guide

| Content Type | Best Media Format | Why |
|---|---|---|
| Conceptual explanation | Text + diagram, or short video | Allows pacing; visual supports abstract ideas |
| Procedural skill | Screencasts, step-by-step video, interactive simulation | Demonstrates the actual process |
| Expert perspective / narrative | Interview video, podcast | Authenticity; human connection |
| Comparison or taxonomy | Infographic, table, interactive | Parallel structure is visually clearer than prose |
| Practice and application | Interactive activity, scenario, quiz | Requires learner action |
| Reflection | Written prompt, journal, discussion | Internal processing; articulation |
| Debate / multiple perspectives | Discussion forum, video debate, case analysis | Dialogue and comparison |
| Data or statistics | Chart, graph, visualisation | Visual representation of quantitative information |

### When Video Is and Isn't the Right Choice

**Video works well for:**
- Demonstrations of physical skills or processes
- Expert perspectives and human stories
- Content where tone and emotion matter
- Lectures where the presenter's presence adds value

**Video is often not the best choice for:**
- Dense conceptual content (learners can't search or skim video easily)
- Reference material learners will return to repeatedly (text is faster to navigate)
- Content that will need frequent updating (video is expensive to re-record)
- Cases where accessibility challenges outweigh benefits (always add captions and transcripts)

## Instructional Media Production Notes

### Video Production (Basic)
- **Length:** Aim for 3–8 minutes per segment. Anything over 12 minutes should be reconsidered.
- **Captioning:** Always. Auto-captions need human review.
- **Transcript:** Provide alongside every video for accessibility and preference.
- **Talking heads vs. screencasts:** Talking heads for connection and presence; screencasts for demonstrations.
- **Production quality:** Lighting and audio matter more than camera quality. Bad audio is unwatchable.

### Audio / Podcast
- Useful for commuting learners, narrative content, expert interviews
- Always provide a transcript
- Aim for 10–20 minute episodes for standalone audio

### Graphics and Visual Design
- Use visuals to clarify, not decorate
- Diagrams should have alt text and be described in surrounding text
- Consistent visual style across the course reduces cognitive load
- Avoid clip art; use high-quality photography or purpose-built illustration

### Interactive Activities (H5P, Articulate Rise, etc.)
- Use for practice, formative feedback, branching scenarios
- Ensure mobile compatibility
- Every interactive element needs a non-interactive fallback for accessibility

## LMS Course Design

The LMS is the learning environment — its structure, navigation, and consistency directly affect the learner experience.

### Course Site Design Principles
- **Consistent structure across modules** — same headings, same sequence, same formatting
- **Clear navigation** — learners should always know where they are and what to do next
- **Scannable layout** — chunked content, meaningful headings, not walls of text
- **Instructions that stand alone** — every activity prompt should be comprehensible without additional context
- **Visible alignment** — show learners how this week's activities connect to the stated outcomes

### Module Structure (Standard Template)
```
📁 Module X: [Title]
  📄 Module Overview (outcomes, topics, time estimate)
  📄 [Content item 1]
  📄 [Content item 2]
  🎯 [Formative activity]
  📄 [Content item 3]
  🎯 [Formative activity or discussion]
  📋 [Assignment / assessment link, if applicable]
  📄 Module Summary and Looking Ahead
```

## Content Development Checklist

- [ ] Storyboard approved by SME before full development begins
- [ ] Each module has a clear introduction with outcomes
- [ ] Content is chunked and sequenced logically
- [ ] Media types are matched to content and learning goals
- [ ] All videos have captions and transcripts
- [ ] All images have alt text
- [ ] All activity instructions are clear and self-contained
- [ ] LMS course structure is consistent across all modules
- [ ] Links and embedded media have been tested
- [ ] Draft content has been reviewed by SME for accuracy
- [ ] Content is reviewed for accessibility (see `08_accessibility_and_inclusivity.md`)
