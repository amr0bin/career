# 12 · Templates Index

## Overview

This file is a master index of reusable templates referenced throughout this repository. Each entry describes the template, which workflow stage it supports, and where to find or adapt it.

Templates are starting points — always adapt them to your institutional context, the specific project, and the preferences of your SME.

> ✅ The core templates now exist as Markdown in [`templates/`](templates/) and are marked **✅** below; copy one into a project folder and adapt it. Unmarked entries are still to build.

## How to Use This Index

1. Identify the workflow stage you're working on
2. Find the relevant template(s) in the index above
3. Navigate to the `/templates` folder in this repository
4. Copy the template and adapt it for your project
5. Save your adapted version in the project folder, not the template folder

**Template naming convention:**
```
TEMPLATE_[stage-number]_[template-name]_v[version].docx
Example: TEMPLATE_07_assessment-strategy_v1.docx
```
