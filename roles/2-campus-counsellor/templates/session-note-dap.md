# Session Note (DAP)

> Template · Every session, same day · Blank form: copy into the institution's or practice's own system. Never store a real student's or client's information in this repository.

**Date / session #:**  **Duration:**  **Modality:** in person / video

**D — Data:** what the client reported and what was observed (behavioural, factual)

**A — Assessment:** progress against goals; measures; risk status

**P — Plan:** interventions used; homework; next session; consultations or referrals

Write it as if the client will read it.
