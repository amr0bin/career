# Essential Requirements Consultation (with Faculty)

> Template · When an accommodation may affect a course requirement · Blank form: copy into the institution's or practice's own system. Never store a real student's or client's information in this repository.

| Question | Notes |
|---|---|
| What outcome does this assessment measure? (the **construct**) | |
| Is the current format the only way to show it, or one **method**? | |
| Where is the requirement documented, and who set it? | |
| Is it rationally connected to the programme's purpose and adopted in good faith? | |
| Is it reasonably necessary — what alternatives have been tried or considered? | |
| Would the alternative cause undue hardship (cost, health and safety)? Evidence? | |
| Agreed outcome | |
| Could a universal design change make this accommodation unnecessary next term? | |

Test: *Meiorin* (rational connection, good faith, reasonable necessity to the point of undue hardship); *Moore* (meaningful access to education).
