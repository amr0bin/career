# Peer Facilitator Guide

> Template · Facilitator training and reference · Blank form: copy into the institution's or practice's own system. Never store a real student's or client's information in this repository.

1. **Role:** what a peer facilitator does and does not do
2. **Session structure:** arrival, check-in, making, optional sharing, close
3. **Creative prompts:** the prompt library; adaptations for access
4. **Holding the room:** pacing, silence, when someone is distressed
5. **Referral thresholds:** see the referral thresholds template
6. **Self-care and supervision:** monthly facilitator supervision; debrief after each session
7. **Records:** attendance counts and facilitator notes about the session, not about individuals
8. **Evaluation:** feedback form each cycle (see `../../structures/PROGRAM_EVALUATION_AND_PRACTICE_REFLECTION.md`)
